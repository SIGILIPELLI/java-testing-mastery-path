# Java Testing Mastery Path

A free, structured, module-wise software testing training program using Java — manual QA fundamentals and test automation, entry level to master level, with templates and runnable code in every module and a hands-on project at the end of each level.

**Live site:** https://sigilipelli.github.io/java-testing-mastery-path/

## Contents

- **Level 1 · Entry** — testing fundamentals, test case design, defect management, and first automated tests with JUnit 5, Selenium and TestNG
- **Level 2 · Intermediate** — Page Object Model, advanced Selenium/TestNG, API testing, reporting
- **Level 3 · Advanced** — BDD with Cucumber, mocking, CI/CD, Selenium Grid, performance and mobile testing
- **Level 4 · Master** — test architecture at scale, shift-left, contract testing, quality gates, QA strategy
